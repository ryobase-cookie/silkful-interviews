# SILKFULL PRO — Veterinary Voice

動物病院専売サプリメント「SILKFULL PRO」を実際に臨床で使っている獣医師の先生方の声を届ける、インタビュー記事サイトです。

## 🌐 公開URL

**https://kazuto32desu.github.io/silkful-interviews/**

このリポジトリの `main` ブランチに push すると、**1〜2分で自動的に上記URLに反映**されます（GitHub Pages による自動デプロイ）。

## 📁 リポジトリ構成

```
silkful-interviews/
├── index.html              ← 記事本体（草坂先生インタビュー）
├── images/                 ← 記事中の写真
│   ├── IMG_7192.jpg        ← 病院外観
│   ├── IMG_7197.jpg        ← サンプルバスケット
│   ├── IMG_7199.jpg        ← 草坂先生ポートレート
│   ├── IMG_7200.jpg        ← 製品ショット（未使用）
│   ├── IMG_7201.jpg        ← 製品ショット（本文中）
│   ├── IMG_7202.jpg        ← 製品ショット（ヒーロー）
│   └── IMG_7203.jpg        ← 院内棚（未使用）
├── README.md               ← このファイル
├── CONTRIBUTING.md         ← 編集ルール（必読）
└── .gitignore
```

## ✏️ 編集したい方へ

編集ルール・推奨フローは [CONTRIBUTING.md](./CONTRIBUTING.md) にまとめています。**初めて編集する前に必ず読んでください。**

### クイックスタート

| やりたいこと | 推奨ツール |
|---|---|
| 文言の小さな修正・誤字直し | [GitHubのWeb UI](https://github.com/kazuto32desu/silkful-interviews/blob/main/index.html)（鉛筆アイコン） |
| 複数箇所の編集・画像の差し替え | [GitHub Desktop](https://desktop.github.com/) |
| 本格的な構成変更 | ローカルで `git clone` してエディタで編集 |

### 編集権限について

- このリポジトリは **Public（公開）** ですが、**push 権限は Collaborator のみ** です
- Collaborator 追加は管理者（@kazuto32desu）にご連絡ください

## 🚨 編集前の必読事項

このサイトは **薬機法（医薬品医療機器等法）の対象** になる可能性のあるコンテンツを扱っています。次の表現は使わないでください：

- ❌ 「効果がある」「効く」「治る」などの効能を断定する表現
- ❌ 成分名を出して機能を説明する表現
- ❌ 「治療」「予防」など医療行為を示唆する表現

詳細は [CONTRIBUTING.md](./CONTRIBUTING.md) を参照してください。
